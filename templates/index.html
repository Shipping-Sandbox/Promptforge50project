Example task · PDF → Podcast
ROUGH PROMPT
Build me a website that lets people upload PDFs and turn them into podcasts. It should understand the PDF, make a good conversation, create audio, and let people listen and download it.
CLARIFYING QUESTIONS
01

What should the podcast feel like?

✓ Two hosts having a natural, curious conversation.
02

How should long PDFs be handled?

✓ Preserve the whole document, but create chapters so listeners can jump around.
03

What should users receive at the end?

✓ Streaming audio, chapter list, transcript, and MP3 download.
04

How much control should the creator have?

✓ Let them choose length, voice style, language, and episode title.
WHAT PROMPTFORGE WOULD BUILD
Extract the source

Turn the uploaded PDF into clean, page-aware text before asking a model to reason over it.

Design the episode

Convert the source into a structured two-host conversation without inventing claims.

Generate speech

Produce consistent voices for each speaker and return audio files for every chapter.

Build the audio layer

Join chapter clips, normalize loudness, and create one clean downloadable episode.

Save the result

Keep the source, generated assets, chapters, and transcript linked to one episode.

Ship the product

Put the upload → processing → playback experience online with a simple production path.

REFINED PROMPT

        

          Build a responsive web app that accepts a user PDF, extracts its text with page boundaries preserved, and turns the document into a chaptered podcast. Use a two-host conversation format with natural back-and-forth, factual fidelity to the source, and no invented claims. Let the user choose episode length, language, voice style, and title. Generate a transcript alongside the audio. Create each chapter as separate audio, merge and loudness-normalize the final episode, store the source and generated assets with episode metadata, and provide streaming plus MP3 download. Keep the processing pipeline asynchronous, show progress by stage, and make every generated artifact traceable back to the source pages.
